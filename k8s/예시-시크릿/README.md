# 예시 시크릿 — ★여기 있는 파일은 절대 클러스터에 적용하지 않습니다

값 자리에 `"여기에-넣지-말-것"` 만 들어 있는 **모양 안내서**입니다.
실제 값은 **카카오클라우드 Secrets Manager** 에 있습니다.

## ⚠️왜 앱 폴더에서 빼냈나 (0807)

```
전   k8s/backend/20-secret.예시.yaml   ← ★앱 경로 안에 있었습니다
```

★**ArgoCD 는 경로 안의 모든 yaml 을 적용합니다.** 그래서 Sync 를 누르면
**살아 있는 `backend-secret`(항목 10개 · DATABASE_URL · JWT_SECRET_KEY · PORTONE …)이
`"여기에-넣지-말-것"` 짜리 2개로 갈아치워집니다.** 서비스가 죽습니다.

★**첫 Sync 를 누르기 직전에 발견**해서 막았습니다.

**두 겹으로 막아 두었습니다.**

```
① 앱 경로 밖으로 옮김        k8s/예시-시크릿/
② 확장자를 .yaml 이 아니게    *.yaml.예시
③ 앱 정의에 exclude 추가      directory.exclude: '{*.예시.yaml,*.yaml.예시}'
```

## 실제 시크릿은 이렇게 만듭니다

각 파일 위쪽 주석에 `kubectl create secret …` 명령이 적혀 있습니다.
**값은 화면에 찍지 말고** 파이프·stdin 으로 넘기고, **길이로만** 확인합니다.
