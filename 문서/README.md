## 쓸 때 규칙

- **새 문서는 폴더 안에 만든다.** 최상위는 정본 4개로 고정.
- **낡은 것은 지우지 말고 `09-옛-` 을 붙여 같은 폴더에** 둔다.
  지우면 "왜 없어졌지"가 남고, 두면 "이건 낡은 것"이 보인다.
- **정정은 같은 턴에 관련 문서 전부에** 반영한다. 한 곳만 고치면 갈라진다.
- ★**캡처 이야기는 강사님 문서에 안 쓴다.** 내부 문서에는 쓴다.
