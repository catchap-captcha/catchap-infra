**★push 권한 — 확인 완료 (2026-07-30)**

보면 올리지 않고도 알 수 있었습니다.**

```
토큰요청 (범위 없음 = docker login)                          200   access=[]
```

**`push,pull`을 요청했는데 돌아온 권한은 `pull`뿐입니다.** 즉 `프로젝트 리더`로는 push가 안 됩니다.

> **이미지 Push는 Container Registry 관리자와 프로젝트 멤버 권한이 있어야** 할 수 있습니다.
> **이미지 Pull은 해당 프로젝트에 속한 멤버라면 누구나** 할 수 있습니다.

★**저장소별 `리포지토리 멤버`로 우회 불가** — 그 화면은 *"프로젝트에 속하지 않은 멤버"* 용이고,
콘솔이 후보 검색에 `user_type=user`를 고정해 **서비스 계정은 목록에 안 나옵니다**
(`{"users":null}` · "추가할 수 없는 계정입니다").
→ **pull(런타임)은 `catchap-ops`로 해결. push는 빌드 시점에 `프로젝트 멤버` 계정으로.**
