# 설정값 전수 조사 — 무엇을 금고에 두고 무엇을 ConfigMap 에 둘까

**2026-08-05.** 사장님 질문 — *"공개값은 안 넣는게 좋아? 그럼 전체 다 조사해줘"*

★**대상 = 백엔드 설정 60개** (구워진 이미지 안 `app/core/config.py` 에서 읽음).
값은 하나도 안 봤습니다. **코드가 그 값을 어디로 보내는지**만 봤습니다.

---

## 0. 판정 기준

```
브라우저까지 가는가?   →  간다면 ★비밀이 아니다. ConfigMap 에 둔다
                          안 간다 + 자격증명이다  →  금고
                          안 간다 + 자격증명 아님  →  ConfigMap
```

★**「비밀값이 ConfigMap 에」가 진짜 위험합니다** — 클러스터를 볼 수 있는 사람이 다 읽습니다.
**「공개값이 금고에」는 새는 게 아니라 자리를 잘못 잡은 것**이고, 값 세 가지를 치릅니다.

```
① 이름이 뭉뚱그려진다        무엇이 들었는지 안 밝혀진다 (0805 에 실제로 겪음)
② 공개값을 바꿀 때 금고를 건드린다   감사 기록이 「비밀 접근」으로 오염된다
③ 기동할 때 읽을 시크릿이 늘어난다  실패할 지점이 늘어난다
```

### ⚠️판정 방법과 그 한계 — 도구가 한 번 틀렸다

처음에 **AST 로만** 판정했다가 **틀렸습니다.**

```
AST 판정   "7개는 코드가 안 쓴다"
실제       ★6개는 쓴다.  getattr(settings, "SENTRY_DSN", "") 처럼 ★문자열로 접근하는 코드를 못 봄
```

그다음 정규식으로 넓혔더니 이번엔 **오탐**이 났습니다.

```
KAKAOPAY 3개    "응답에 실림"  → ★틀림. 게이트웨이 호출에만 쓰는 서버 전용
CORS_ORIGINS    "안 씀"       → ★틀림. cors_origin_list 프로퍼티 경유 (main.py:102)
PAYMENT_*_URL   "안 씀"       → ★틀림. payment_success_url 프로퍼티 경유
```

★**최종 판정은 응답 스키마를 직접 읽어서 했습니다.** 아래 A 가 그것입니다.

---

## A. 브라우저까지 가는 값 — ★정확히 3개

`GET /courses/{id}/checkout` 이 돌려주는 `CheckoutOut` 스키마에 들어 있습니다
(`api/v1/endpoints/payments.py:233~245`).

```
toss_client_key      ← TOSS_CLIENT_KEY
portone_store_id     ← PORTONE_STORE_ID
portone_channel_key  ← PORTONE_CHANNEL_KEY
```

| 이름 | 지금 어디 | 있어야 할 곳 |
|---|---|---|
| `PORTONE_CHANNEL_KEY` | ★**금고**(`catchap-portone-keys`) | **ConfigMap** — 자리 틀림 |
| `PORTONE_STORE_ID` | 어디에도 없음 | ConfigMap |
| `TOSS_CLIENT_KEY` | 어디에도 없음 | ConfigMap (토스를 쓸 때) |

★**이 셋은 결제 화면을 여는 사람이면 개발자도구로 다 봅니다.** 숨길 수 없는 값입니다.

## B. 서버 전용 비밀 — 금고에 있어야 하는 것

### ✅ 이미 금고에 있고 자리가 맞는 것 (5)

```
JWT_SECRET_KEY         catchap-auth-jwt-secret
SMTP_APP_PASSWORD      catchap-smtp-app-password
STT_WORKER_TOKEN       catchap-stt-worker-token
METRICS_INGEST_TOKEN   catchap-metrics-ingest-token
PORTONE_API_SECRET     catchap-portone-keys
```

### ⬜ 오늘 넣기로 한 것 (3)

```
DATABASE_URL           catchap-database-url          ★접속 확인 완료 (테이블 99개)
MEDIA_S3_ACCESS_KEY    catchap-media-s3-keys   ★버킷 조회 확인 완료
MEDIA_S3_SECRET_KEY    〃
```

### ⬜ 비밀인데 아직 아무 데도 없는 것

| 이름 | 쓰는 곳 | 없으면 |
|---|---|---|
| ★`MAIN_CAPTCHA_SITE_SECRET` | `clients/main_captcha_client.py:37` · `services/lecture_service.py:77` | **강의 캡차 연동이 꺼집니다**(둘 다 있어야 켜지는 게이트) |
| `ANTHROPIC_API_KEY`·`OPENAI_API_KEY` | `clients/ai_client.py` | ★**DB 값이 우선**입니다(`settings_service.py:83·88`) — 운영 콘솔에서 넣을 수 있어 금고가 꼭 필요하지 않습니다 |
| `SENTRY_DSN` | `main.py:52` | 비면 조용히 비활성(no-op). 급하지 않음 |
| `PORTONE_WEBHOOK_SECRET` | ★**참조 0건** | 웹훅 검증이 아직 구현 안 됨. **지금은 필요 없습니다** |

### ★★결제는 포트원만 쓰기로 확정 (0805 사장님 결정)

```
TOSS_CLIENT_KEY · TOSS_SECRET_KEY                        → ★안 넣는다
KAKAOPAY_CID · KAKAOPAY_SECRET_KEY · KAKAOPAY_CID_SECRET  → ★안 넣는다
```

★**비워 두면 그 수단이 자동으로 안 켜집니다**(`toss_enabled`·`kakaopay_enabled` 가 false).
**설정을 지울 필요도, 코드를 고칠 필요도 없습니다.** 그냥 안 넣으면 됩니다.

★★**그래서 결제를 켜는 데 필요한 것은 `PORTONE_STORE_ID` 하나뿐입니다.**
나머지 둘(`CHANNEL_KEY`·`API_SECRET`)은 **이미 금고에 있습니다.**
그리고 `STORE_ID` 는 **공개값이라 ConfigMap 에 넣으면 됩니다 — 시크릿 작업이 없습니다.**

⬜**값은 포트원 콘솔에서 받으셔야 합니다.** 저장소 전체를 검색했지만 없습니다(0805).

## C. 비밀이 아닌 나머지 — ConfigMap

주소·숫자·플래그·경로입니다. 지금 ConfigMap 에 있는 것들은 자리가 맞습니다.

```
ENV · FRONTEND_URL · BACKEND_URL · CORS_ORIGINS
SMTP_HOST · SMTP_PORT · SMTP_USER · MAIL_FROM · MAIL_FROM_NAME · MAIL_REPLY_TO
MEDIA_* (버킷·엔드포인트·리전·접두사·백엔드) · MAX_*_BYTES
STT_WORKER_URL · MAIN_CAPTCHA_URL · DRAG_CAPTCHA_ENABLED · CAPTCHA_* 8개
PAYMENT_*_URL · PAYMENT_MOCK_ENABLED · LECTURE_MEDIA_DIR · LLM_MODEL
JWT_ALGORITHM · ACCESS_TOKEN_EXPIRE_MINUTES · REFRESH_TOKEN_EXPIRE_DAYS
BOT_ESCALATION_MODE · BOT_SUSPICION_THRESHOLD
```

★**`ACCESS_TOKEN_EXPIRE_MINUTES`·`REFRESH_TOKEN_EXPIRE_DAYS` 는 이름에 `TOKEN` 이 들어가지만
그냥 숫자(분·일)입니다.** 제 자동 판정이 이걸 비밀로 오해했습니다.

★**비밀이 ConfigMap 에 들어가 있는 경우는 ★한 건도 없었습니다.** 위험한 방향은 깨끗합니다.

## D. ★★배포하면 결제 수단이 0개입니다

`payments.py:51 _available_providers()` 가 켜진 수단만 목록에 넣고,
각 수단은 **키가 다 있어야** 켜집니다.

```
toss_enabled      TOSS_CLIENT_KEY + TOSS_SECRET_KEY          → ★안 쓰기로 함  ✗
kakaopay_enabled  KAKAOPAY_CID + KAKAOPAY_SECRET_KEY         → ★안 쓰기로 함  ✗
portone_enabled   STORE_ID + CHANNEL_KEY + API_SECRET        → ★STORE_ID 만 없음  ✗
payment_mock      PAYMENT_MOCK_ENABLED and not is_production → prod 라 꺼짐  ✗
```

★**하나라도 비면 아예 안 켜는 설계입니다** — 결제창만 띄우고 승인 검증을 못 하는 상태를
막습니다. 좋은 설계지만, **지금 배포하면 결제 화면에 수단이 하나도 안 뜹니다.**

⚠️**이건 배포를 막지는 않습니다.** 로그인·강의·시청은 됩니다. 다만 **알고 가야 합니다.**

★★**막고 있는 것은 `PORTONE_STORE_ID` 값 하나입니다.** 그것만 넣으면 결제가 켜집니다.
공개값이라 **ConfigMap 한 줄**이면 끝나고, 금고를 건드릴 일이 없습니다.
