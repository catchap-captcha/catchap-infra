## ⑥ 킵 — 건강검진하는 DNS 로 이전 (컷오버 끝난 뒤)

★**루트 도메인만 고가용성 보호를 못 받습니다.** 컷오버해도 남는 한계입니다.

```
www · api    CNAME → 고가용성 그룹 → ★카카오가 산 쪽으로 보냄. 안전
루트          A 두 줄 → ★DNS 는 건강검진을 안 해서 죽은 IP 도 계속 알려 줌
```

★**리다이렉트로는 못 풉니다.** `catchap5.com` → `www` 308 은 **살아 있는 입구에 닿은
뒤에야** 일어납니다. 받은 A 레코드가 죽어 있으면 **308 을 받을 기회조차 없습니다.**

```
입구 둘 다 정상    아무 문제 없음
입구 하나 죽음     루트로 온 사람의 절반이 첫 연결 실패
                 → 브라우저가 다른 A 로 재시도하면 회복(요즘 브라우저는 대개 함)
                 → ★www 로 온 사람은 전부 정상
```

**한 줄만 적었을 때(100% 실패)보다는 확실히 낫지만 완전하지 않습니다.**

**풀려면** — 건강검진해서 **죽은 IP 를 답에서 빼 주는 DNS** 로 옮겨야 합니다.
가비아·카카오클라우드 DNS 둘 다 그 기능이 **없습니다**(ALIAS/ANAME 도 없음, 문서 확인).
Cloudflare 등이 대안입니다.

⚠️**지금 하면 안 되는 이유** — DNS 를 통째로 옮기면 **MX·SPF·DKIM·DMARC·`_acme-challenge`
까지 전부 같이 옮겨야** 하고, 하나라도 빠지면 **메일이 죽습니다.**
**컷오버가 끝나고 안정된 뒤에 따로** 합니다.

## ★★비밀값을 어디에 두나 — 0805 에 방향이 바뀌었습니다

★**「13건을 쿠버네티스 시크릿에 넣는다」는 낡은 계획이었습니다.**
[00-아키텍처-설계.md](../00-아키텍처-설계.md) 2-E 에서 이미 **앱이 기동할 때 금고에서
직접 읽는 방식**으로 정해 뒀고, **그 코드가 이미 이미지 안에 들어 있습니다**
(`app/core/secrets_loader.py` · 0805 실제로 구동해서 확인).

```
0805 구동 결과   시크릿 5건 → 환경변수 6개 주입 성공 (★값을 한 번도 화면에 안 찍음)
  JWT_SECRET_KEY  SMTP_APP_PASSWORD  STT_WORKER_TOKEN
  METRICS_INGEST_TOKEN  PORTONE_API_SECRET  PORTONE_CHANNEL_KEY
```

★**왜 이게 나은가** — K8s Secret 은 이름과 달리 **암호화가 아니라 base64** 라서 etcd 에
사실상 평문으로 들어갑니다. Secrets Manager 는 **kms11 로 암호화**되고 **누가 언제
읽었는지 감사 기록**이 남습니다. 값을 바꿀 때 **쿠버네티스를 안 건드려도** 됩니다.

★**키 이름을 환경변수 이름 그대로** 넣으면 로더가 매핑표 없이 주입합니다.

★**`ENV=prod` 는 스위치가 아니라 관문입니다.** 백엔드가 부팅할 때
JWT 32자·CORS 에 `*` 금지·SMTP 필수를 검사하고 **하나라도 걸리면 부팅을 거부**합니다.
