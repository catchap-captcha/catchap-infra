## 7. 되돌리는 법

```
main 을 잘못 옮겼다   git push origin <옛 해시>:main --force    옛 해시는 2절에 있음
가지를 잘못 지웠다     catchap-legacy 에 있습니다 — 도로 push 하면 됩니다
이름을 바꿨다          GitHub 이 옛 이름을 리다이렉트합니다. 되돌리기도 됩니다
```

★**옮기기 직전에 고유 커밋 수를 다시 셉니다.** 숫자가 달라졌으면 **멈추고 확인** —
그 사이 누가 push 한 것입니다.

⚠️**찌꺼기 참조 하나** — 네 저장소 모두에 `refs/remotes/origin/origin` 이라는 오래된 참조가
있습니다(로컬만의 문제). 정리하려면 `git remote prune origin`.
