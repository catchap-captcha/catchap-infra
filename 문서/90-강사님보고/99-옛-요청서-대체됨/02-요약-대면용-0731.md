## 1순위 — Kubernetes 권한 (`kubectl` 한 줄) **★유일하게 대체 수단이 없습니다**

```bash
kubectl create clusterrolebinding catchap-ops-admin \
  --clusterrole=cluster-admin \
  --user=catchap-ops-kc-sfacspace05@kc.serviceaccount.com
```

- 저희 계정은 **인증까지 통과**하고 권한만 없습니다 (`401`이 아니라 **`403`**)
- **콘솔에 이 메뉴가 없고** Kubernetes는 **전용 IAM 역할이 아예 없습니다**
  → 프로젝트 역할을 아무리 주셔도 이건 대체되지 않습니다. 실제로 `프로젝트 관리자`를 받았지만
  클러스터 API는 여전히 `403`입니다
- 이 클러스터는 **웹훅 인가자**를 써서(`webhook authorizer does not support user rule resolution`)
  밖에서는 권한 경로를 확인할 수 없습니다
- `edit`이 아니라 **`cluster-admin`** 인 이유 — 인그레스 배포 YAML이 `Namespace`·`ClusterRole`·
  `ClusterRoleBinding`·`IngressClass` 같은 **클러스터 범위 리소스**를 만들어 `edit`으로는 막힙니다
- **다른 조에 영향 없습니다** — K8s 권한은 클러스터 안으로만 미치고, 이 클러스터는 워커 2대 모두
  `Team1-VPC`에 있는 **1조 전용**입니다
- ⚠️ **엔드포인트가 프라이빗이라 VPC 안에서 실행**하셔야 합니다.
  사무실 PC에서 안 되시면 **저희 점프서버(`210.109.82.148`)에 계정을 만들어 두겠습니다**

같이 주시면 좋은 것: **클러스터 CA 인증서**(kubeconfig의 `certificate-authority-data`).
없으면 TLS 체인 검증을 못 해서 지금은 서버 인증서 지문 2개를 고정해 쓰고 있습니다.

## 2순위 — 시크릿 **1건** 삭제 (1분)

```
Secrets Manager → 시크릿 → catchap-backend-prod  (버전 0 · 미완성)
  → 체크박스 → [삭제]
```

**접근 제어가 `사용`이라 저희 계정에서는 체크박스 자체가 비활성**입니다(ID도 마스킹).
API로도 안 됩니다 — ID가 `78861f0a-****-****-****…` 형태로 와서 요청이 성립하지 않습니다.

★ 같이 요청드렸던 **`catchap-team1-probe`는 저희가 지웁니다** — 저희가 이름 규칙 시험용으로
만든 것이고 코드 참조가 0건입니다(`kms12`·접근 제어 미사용·프로덕션 값 아님).

★**참고로 시크릿 삭제에는 선행 조건이 있습니다** — *"모든 버전이 폐기 완료된 상태인 경우
시크릿을 삭제할 수 있습니다"*(정지 상태 + 기본 버전 해제). 그래서 **버전 폐기 → 정지 → 삭제**
3단계를 거쳐야 합니다. `catchap-backend-prod`는 **버전 0 · 미완성**이라 그 조건은 이미 맞을 수
있는데, **저희 계정에서는 체크박스가 비활성**이라 선택 자체가 안 됩니다. 그래서 이 한 건만
부탁드립니다.

`프로젝트 관리자(Admin)` 권한을 가진 계정이 07-29 17:53에 만들어져 있었습니다. 중복으로 판단해
**미사용 전환 → Cloud Trail 확인 → 삭제**까지 했습니다. `catchap-monitoring`(07-27 생성,
`Alert Center 매니저` 하나뿐)도 같이 정리했습니다.

**검증 근거** — 두 계정 모두 **Cloud Trail 이벤트가 생애 전체에서 0건**이었습니다.
Cloud Trail은 읽기 작업까지 기록하므로, **한 번도 인증·호출된 적이 없다는 뜻**입니다.

```

catchap-monitoring   ID 53c6a813bb124c1f88d47dfe4855b254   생성 07-27 10:37   이벤트 0건
```

혹시 쓰실 계획이었다면 말씀해 주십시오. 같은 역할로 다시 만들면 됩니다.
★결과적으로 **프로젝트에 `프로젝트 관리자`를 가진 서비스 계정이 없어졌습니다.**

**2) Deployflow를 쓰기를 기대하셨습니까?**

저희 클러스터는 엔드포인트가 **프라이빗**이라 Deployflow 배포 대상이 될 수 없습니다
(문서: *"퍼블릭 엔드포인트가 할당된 클러스터만"*). 퍼블릭으로 바꾸면 apiserver가 인터넷에
노출되니 **프라이빗 그대로 두고 `kubectl`로 배포**하려 합니다.
